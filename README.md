# a9Edit

a9Edit は、範囲選択ラッチ・日本語文字数での折り返し・ルビや圏点の表示・禁則候補の警告を備えたテキストエディタです。

基本機能は本家のEdit(https://github.com/microsoft/edit) に準拠します。

当リポジトリへフォークされたのは2026/08/19です(このバージョンは`org_edit`ブランチに保持されています)。

本家Editと異なるのは、以下の点です。

- 範囲選択ラッチ
- 折り返し文字数の指定
- ルビ・圏点の縮退表示
- 禁則候補の警告表示と設定ファイル

## 範囲選択ラッチ

Ctrl+Shift+矢印キーで、その移動前の位置を始点とする選択ラッチを開始します。開始キーの矢印移動も実行され、選択範囲がすぐに表示されます。

- ターミナルによって、行をまたいだshift+カーソルキーによる範囲選択の拡張が不可能なことがあるため、その対策として実装したものです。
- 大きな範囲を選択する際にshiftキーが外れてしまい選択し直しになるストレスの軽減にもなります。
- Ctrl+矢印・Shift+矢印だけではラッチを開始せず、従来の操作になります。
- ラッチ中は、矢印キーだけで選択範囲を拡大・縮小できます。Home・End・PageUp・PageDown でも選択を続けます。
- Ctrl+Shift+矢印を再度押しても始点は変わりません。開始時の移動は単語単位ではなく、通常の矢印1回分です。
- Enter は改行せずラッチを終了し、選択範囲を保持します。その後、矢印キーを押すと通常の移動に戻ります。
- Esc はラッチと選択範囲を解除します。
- Ctrl+C（コピー）や Ctrl+S（保存）では、ラッチと選択範囲を保持します。
- 文字入力は選択範囲を置き換え、Backspace・Delete・切り取り・貼り付けなどの編集ではラッチを終了します。未対応キーやウィンドウのリサイズでは終了しません。
- ラッチ中は最下段のステータスバーに「選択ラッチ」を表示します。ルビ・圏点の非表示部分には止まりません。
- ラッチは文書ごとに保持され、検索欄などの1行入力欄では開始しません。

※従来の Alt+R によるトグル操作と、メニューの「範囲選択の開始/終了」は廃止しました。

## 折り返し文字数の指定

起動時に `--wrap=N` を指定すると、日本語（全角）`N` 文字分の幅で表示を折り返します。半角文字2文字を日本語1文字分として数えます。引数と値の間にスペースは挟みません。

```bash
./target/release/a9Edit --wrap=20 文書.txt
```

- 禁則処理を許容しない前提で、組版等の版面を意識した筆記を可能とします。
- 全角文字を2桁、半角英数字を1桁として数えます。`--wrap=20` は全角20文字分（半角40文字分）です。結合文字は端末上の表示幅に従います。タブは設定されたタブ幅で計算します。
- 指定できるのは正の整数です。指定すると折り返しが有効になり、起動後に開くファイルや新規文書にも適用されます。
- 端末の本文領域が指定幅より狭い場合は、その領域の幅で折り返します。端末を広げると指定幅に戻ります。
- 指定時は単語や句読点を移動させず、指定幅に収まる文字の境界で折り返します。禁則処理対象の警告表示は今後の対応です。
- 折り返しは表示上だけの処理です。保存する本文に改行は追加しません。
- `View` メニューの折り返し切り替え（`Alt+Z`）で無効・再有効にできます。再有効にすると指定幅が使われます。
- `--wrap=20` のように指定した場合、表示メニューの折り返し項目にも `(20)` を表示します。チェックは折り返しの有効・無効、数値は指定した日本語文字数を示します。
- 引数を省略すると従来の動作になります。`--` 以降はファイル名として扱われます。

## ルビ・圏点の縮退表示

`｜漢字《かんじ》` のようなルビ記法は、本文では母字の「漢字」だけを黄色で表示します。
母字にカーソルを合わせると、最下部から2行目のメッセージ領域に `ルビ:[かんじ]` を表示します。母字から離れると、このメッセージは消えます。
`《《圏点》》` も、本文では母字の「圏点」だけを黄色で表示し、カーソルを合わせるとメッセージ領域に `圏点:[﹅]` を表示します。
従来のステータスバーは最下段に残り、本文の表示領域は1行少なくなります。

- ルビ指定や圏点指定が、指定記号により表示上の文字数が増えてしまうことで禁則処理の回避・解消ができなくなることを防ぎます。
- 追加の起動オプションは不要です。折り返し幅は、記号や読みを除いた母字の表示幅で計算します。
- 保存する本文には、元の `｜漢字《かんじ》` を保持します。母字全体を選択してコピーした場合も、ルビ記法を含めてコピーします。
- 母字内の左右移動では、非表示の記号や読みには止まりません。母字の一部を削除した場合は読みを保持し、母字全体を削除した場合はそのルビ指定も削除します。
- `｜` は全角です。母字・読みが空の記法や、閉じ括弧がない入力途中の記法は、そのまま表示します。改行をまたぐ記法は対象外です。
- 圏点も保存・コピーでは元の `《《母字》》` を保持し、折り返し・移動・選択・削除はルビと同じ扱いです。空の `《《》》` や入力途中の記法、改行をまたぐ記法はそのまま表示します。

## 禁則候補の警告表示と設定ファイル

- `line_start`：表示上の行頭に置けない文字。
- `line_end`：表示上の行末に置けない文字。
- `paragraph_start_allowed`：`line_start` に含まれていても、実際の行（段落）の先頭では許可する文字。
- `inseparable`：折り返し位置で分離してはいけない文字列の配列。各文字列は表示上の2文字以上とし、分離した場合は該当文字列全体を警告します。重なって出現する場合もチェックします。

禁則処理が行われないように文章を調整するため、文章作成中にリアルタイムで警告表示するものです。禁則処理を受け入れない人にしか意味のない設定です。

`--wrap=20` や表示メニューで折り返しを有効にした場合、実際の表示行に合わせて赤文字・黄色背景で警告します。画面が狭い場合は、その画面幅での折り返し位置に従います。折り返しを無効にすると警告表示もなくなります。専用の警告表示オプションは不要です。

判定はルビ・圏点の母字に対して行い、非表示の記号や読みは含めません。ルビ母字の分離も`inseparable` の指定に関係なく警告します。警告色はルビ・圏点の黄色より優先し、選択範囲との重なりは下線で示します。警告箇所にカーソルを合わせると、メッセージ領域に理由を表示します。

本文・保存内容・折り返し位置を自動修正する機能ではありません。`forbidden` 自体を省略すると警告は無効です。各文字列を空にするか `inseparable` を空配列にすると、その設定項目のチェックを無効にできます。不正な型や改行を含む設定は、エラーとして通知します。

設定保存先は Windows では `%APPDATA%\a9Edit\settings.json`、macOS では `~/Library/Application Support/a9Edit/settings.json` です。旧版の設定を引き継ぐ場合は、従来の保存先から新しい保存先へ `settings.json` をコピーしてください。

Linux では `~/.config/a9Edit/settings.json` を起動時に読み込みます。`XDG_CONFIG_HOME` を設定している場合は、その配下の `a9Edit/settings.json` を使用します。`File` → `Preferences` からも編集できます。変更の反映には再起動してください。

既存の JSON に、次の `forbidden` オブジェクトを追加します。既存の `files.associations` などは同じ階層に残せます。

```json
{
  "forbidden": {
    "line_start": "。、）］｝」』",
    "line_end": "（［｛「『",
    "paragraph_start_allowed": "（［｛「『",
    "inseparable": ["……", "――"]
  }
}
```

禁則設定の例は [settings.example.json](settings.example.json) にあります。新規の設定ファイルをメニューから開く場合も、この内容を雛形にします。


## ビルド

このリポジトリでは `crates/a9Edit` にてリリース用バイナリ `a9Edit` を明示的に定義しています。正式な（最適化された）ビルド手順と基本的なインストール例は以下の通りです。

- Release ビルド（ワークスペースのルートで実行）:
  ```bash
  cargo build --package a9edit --release --bin a9Edit
  ```

- 出力バイナリ:
  - 成功するとバイナリは `target/release/a9Edit` に作成されます。

- 実行例:
  ```bash
  ./target/release/a9Edit <file-to-open>
  ```

- システムにインストールする例（管理者権限が必要）:
  ```bash
  sudo cp target/release/a9Edit /usr/local/bin/a9Edit
  ```

- ビルド時の環境変数:
  - ICU の SONAME や組み込む言語の設定は `A9EDIT_CFG_*` 環境変数で指定できます。旧版の `EDIT_CFG_*` は `A9EDIT_CFG_*` に変更しています。必要に応じて `A9EDIT_CFG_ICUUC_SONAME` や `A9EDIT_CFG_ICUI18N_SONAME` を設定してビルドしてください。

注: `crates/a9Edit/Cargo.toml` で `autobins = false` を設定しているため、`a9Edit` を明示的に `--bin` 指定してビルドするか、上記のコマンドを使用してください。

配布用の WinGet ワークフローは手動実行です。a9Edit 用に登録済みのパッケージ ID と公開済みのリリースタグを指定してください。
